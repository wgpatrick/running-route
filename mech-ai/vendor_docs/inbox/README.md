# Vendor documents to add by hand

These sites refuse automated downloads. Put the PDF (or a saved page) in this folder and it will be read into
`mechloop/parts/vendor/`. What each one is needed for:

| Document | Where | Needed for |
|---|---|---|
| Hiwin Linear Guideway technical catalogue (MG series pages) | hiwin.tw or hiwin.com downloads | MGN12 rail and block dimensions, load and moment ratings, accuracy classes, allowable rail parallelism and height error, preload, tapped-hole depth |
| Gates PowerGrip GT2 2 mm belt data (design manual section) | gates.com | belt stiffness, working tension, minimum pulley teeth |
| TMC2209 data sheet | analog.com | driver current and voltage limits, on-resistance (driver heating) |
| Misumi HFS5-2020 extrusion page or catalogue page | misumi-ec.com | section properties, slot width, cut-length tolerance |
| E3D V6 (or Revo) engineering drawings and specifications | e3d-online.com | hotend dimensions, mass, thermistor type |
| BigTreeTech SKR Mini E3 V3.0 specification with output current limits | BigTreeTech product page or manual | bed, hotend and fan output current ratings |
| Data sheets for the exact bed heater pad, thermal cut-off, supply relay, IEC inlet and fans you would buy | the seller | the 14 electrical parts still on typical values |
| T8 lead screw and anti-backlash nut drawing | the seller | nut dimensions, lead accuracy |
| ISO 898-1 proof loads and ISO 273 clearance holes (any fastener handbook table) | | screw strength and hole sizes |
