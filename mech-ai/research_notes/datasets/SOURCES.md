# research_notes/datasets

Fetched 2026-11-15. Each sub-directory has its own SOURCES.md with URL, licence and description. Everything here is untrusted third-party data: parse as CSV/JSON/text only, run Python with `-I`, execute nothing. Total about 46 MB.

| Directory | What | Licence |
|---|---|---|
| `klipper_resonance_psd_corpus/` | 98 resonance-test spectra from 16 repositories, plus an index of 274 files from 62 repositories with peak and damping | MIT / Apache-2.0 / CC0 / GPL-3.0 per repository |
| `helixscreen_belt_plucks/` | 8 raw belt pluck ring-downs, known span | GPL-3.0 |
| `ender3_hotend_twin_logs/` | 9 hotend heat/hold/fan/cool logs with heater duty, and a fitted model | GPL-3.0 |
| `arts_fff_lifecycle_vibration/` | features, maintenance log and 1 of 15 raw vibration recordings | CC BY-SA 4.0 |
| `firmware_fitted_parameters/` | Prusa thermal model and input-shaper defaults, Kalico MPC doc, PID and MPC constants from 216 Klipper and 425 Marlin configs | GPL-3.0 |
| `slicer_profiles/` | Bambu filament flow limits (derived), PrusaSlicer vendor profile | AGPL-3.0 / unstated |
| `community_tables/` | Ellis flow table, Klipper docs | unstated / GPL-3.0 |
| `_first_look/` | plots, numbers and scripts from the first look | ours |
